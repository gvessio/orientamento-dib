# Orientamento DIB

Sito di orientamento del [Dipartimento di Informatica dell'Università degli Studi di Bari Aldo Moro](https://www.uniba.it/it/ricerca/dipartimenti/informatica), dedicato alle scuole secondarie superiori.

**Sito web:** https://gvessio.github.io/orientamento-dib/

## Sviluppo locale

Il sito è realizzato con [Hugo](https://gohugo.io/).

```bash
hugo server -D
```

La pubblicazione su GitHub Pages avviene automaticamente tramite GitHub Actions a ogni push sul ramo `main`.
